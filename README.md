# 🎵 Música del Alma

¡Bienvenido al repositorio de **Música del Alma**! Este proyecto es una aplicación web interactiva desarrollada para compartir y explorar contenido musical.

---

## 🛠️ Tecnologías utilizadas

* **HTML5:** Estructura semántica de la aplicación.
* **CSS3:** Estilos visuales y diseño adaptativo (*responsive design*).
* **JavaScript (ES6+):** Lógica del reproductor e interactividad.
* **Git & GitHub:** Control de versiones y alojamiento de código.
