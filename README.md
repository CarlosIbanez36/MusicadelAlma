# 🎵 Música del Alma

> Una plataforma web interactiva diseñada para explorar, reproducir y conectar con música que inspira y reconecta con tus emociones.

---

## 🌟 Sobre el Proyecto

**Música del Alma** es un proyecto enfocado en ofrecer una experiencia musical envolvente y relajante. Combina una interfaz intuitiva con funcionalidades de reproducción interactiva, listas de reproducción temáticas y un diseño cuidado al detalle.

---

## 🚀 Características Principales

* 🎧 **Reproductor Interactivo:** Control total de reproducción (play, pausa, avanzar, retroceder y barra de progreso).
* 📜 **Listas de Reproducción Temáticas:** Selección de temas organizados por estados de ánimo y géneros.
* 📱 **Diseño Responsive:** Adaptado perfectamente para dispositivos móviles, tabletas y ordenadores.
* 🎨 **Interfaz Sensorial:** Estética visual armoniosa orientada al bienestar y la relajación.

---

## 🛠️ Tecnologías Utilizadas

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Herramientas de Entorno:** Node.js, Visual Studio Code, Live Server
* **Control de Versiones:** Git & GitHub
